# Локальная резервная копия базы PC-Lease

Структура базы хранится в Git через миграции. Данные и пароли в Git не добавляются. Локальные копии находятся в `data/private-backups`, которая исключена из Git. Доступ к папке предоставляется текущему пользователю Windows, администраторам и SYSTEM; копия не зашифрована и зависит от защиты Windows и диска.

Для повторной копии при запущенных локальных службах выполните из папки проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File server/backup-private-local.ps1
```

Скрипт ненадолго останавливает локальный сайт и PostgreSQL, копирует остановленный кластер, побайтово проверяет файлы, сохраняет файл пароля базы и признак включения CRM и снова запускает службы. При ошибке частичную копию использовать нельзя. Автоматическое расписание не настроено: скрипт прерывает работу сайта.

В каждой полной копии папка `cluster` содержит кластер PostgreSQL, а `postgres-password` — необходимый для подключения пароль. Для восстановления сначала сохраните текущую базу отдельно; восстановление выполнять в отдельную тестовую папку с той же версией PostgreSQL, проверить запуск и данные и только затем принимать решение о замене рабочей базы. Не заменяйте действующую базу без отдельного подтверждения владельца. Механизм копирования и восстановления проверен на синтетической базе; восстановление актуальной рабочей копии отдельно не проверялось.

Копии на том же диске не защищают от его отказа. Для полноценной защиты нужна дополнительная копия вне компьютера и отдельное решение о шифровании и хранении ключа. Старые копии в `data/backups` могут иметь более широкие права доступа; проверьте их перед использованием или переносом.
