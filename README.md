# PC-LEASE — Equipment Commerce & Rental Platform

Платформа долгосрочной аренды (лизинга), продаж и гарантийного обслуживания восстановленного IT-оборудования бизнес-класса в Израиле.

Разработано в соответствии с **Техническим заданием v1.0 (Equipment Commerce & Rental Platform | 21.10.2026)**.

---

## 📚 Документация проекта

- **[CHANGELOG.md](./CHANGELOG.md)** — Подробный журнал всех версий, релизов и изменений по ТЗ.
- **[ROLLBACK.md](./ROLLBACK.md)** — Регламент откатов, работы с Git-тегами и восстановления при сбоях.
- **[SPECIFICATION.md](./SPECIFICATION.md)** — Исходный текст Технического задания v1.0.

---

## 🚀 Стек технологий

- **Frontend:** React 18, TypeScript, Tailwind CSS v4, Lucide Icons.
- **Интернационализация:** עברית (Иврит — основной RTL) и English / Русский (LTR) с адаптивным перестроением сетки.
- **Архитектура:** Modular Monolith с независимыми State Machines для продаж, аренды и сервиса.
- **Сборка:** Vite, Node.js.

## 📦 Запуск проекта

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```
   Сервер запустится на `http://localhost:3000`.

3. **Сборка для продакшена:**
   ```bash
   npm run build
   ```
