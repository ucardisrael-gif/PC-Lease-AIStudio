# PC-LEASE — B2B Hardware & Laptop Leasing Platform

Платформа долгосрочной и гибкой аренды (лизинга) и продажи восстановленных бизнес-ноутбуков и микро-ПК для юридических лиц и специалистов (Израиль / Global).

## 🚀 Стек технологий

- **React 18** (TypeScript, хуки, модульная архитектура)
- **Vite** (сверхбыстрая сборка и HMR)
- **Tailwind CSS v4** (современная верстка, адаптивный дизайн, темная/светлая тема)
- **Lucide React** (набор иконок)
- **i18n** (полноценная поддержка двух языков: Русский и Иврит עברית с корректной поддержкой RTL / LTR)

---

## 📦 Быстрый старт на локальном компьютере

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Запуск сервера разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000` (или `http://localhost:5173`).

3. **Сборка для продакшена:**
   ```bash
   npm run build
   ```
   Готовые файлы будут в папке `dist/`.

## 💡 Функциональные особенности

1. **Мультиязычность и RTL:** Переключение языков на лету между Русским и Ивритом (`dir="rtl"` перестраивает весь интерфейс зеркально).
2. **Лизинговый калькулятор:** Автоматический расчет помесячного платежа, сравнение «Покупка vs Аренда», опции сервисного обслуживания и подменного фонда.
3. **Конструктор рабочих мест:** Комплектование одного рабочего места ноутбуком/ПК + монитором 27" 4K + док-станцией Type-C + гарнитурой.
4. **Панель управления (Site Editor):** Возможность редактировать заголовки, цены и видимость блоков прямо в браузере.
