# Исходные логотипы PC-LEASE

В этой папке хранятся все пять файлов, предоставленных владельцем 31.10.2026. Исходные изображения не изменены:

- `logo-transparent.png` — прозрачный горизонтальный логотип; используется на сайте и в PDF.
- `logo-transparent-copy.png` — второй предоставленный экземпляр прозрачного логотипа.
- `logo-dark.png` — вариант на тёмном фоне.
- `icon-transparent.png` — отдельный знак на прозрачном фоне.
- `brand-asset-sheet.png` — таблица вариантов фирменного оформления.

У изображений большие поля; сайт и PDF отображают область логотипа, не изменяя исходный файл. В тёмной теме сайта прозрачный вариант осветляется средствами CSS.
